This is a list of some WWW servers.
It does not include all servers,
and note that one server machine
can serve many databases. See also:
background on [WWW](https://cern.la/hypertext/WWW/TheProject.md) , and data available
by [other protocols](https://cern.la/hypertext/DataSources/ByAccess.md) , data by [subject](https://cern.la/hypertext/DataSources/bySubject/Overview.md)
, [how to make a new server](https://cern.la/hypertext/WWW/Provider/Overview.md) , [test
servers](https://cern.la/hypertext/DataSources/WWW/UnstableServers.md) . If servers are marker
"experimental", you should not expect
anything. The top of the list is
in reverse chronological order of
addition.

[NCSA](http://hoohoo.ncsa.uiuc.edu:80/): National Center for Supercomputing Applictions, Urbana Champain, IL, USA. Experimental. [IN2P3](http://info.in2p3.fr.:80/): Lyon, France. [KVI](http://kviexp.kvi.nl/): Kernfysisch Versneller Instituut (nuclear physics accelerator institute), Groningen, Netherlands. VMS server. [CWI](//ftp.cwi.nl/pub/www/default.html): Center of Mathematics and Computer Science, Amsterdam. FTP server for hypertext, including Gnu TeXInfo stuff as hypertext. [Cornell](http://fatty.law.cornell.edu.:80/usr2/wwwtext/lii.table.html): Legal information: US Intellectual Property Statustes on line. [ZEUS](http://zws009.desy.de:2784/): ZEUS experiment at DESY, Hamburg, Germany. [.At least 2 servers] [KEK](//kekux.kek.jp/kek/html/kek.html): KEK, Tsukuba, Japan. Experimental only. [FTP hypertext, http server later) [DESY unix server](http://apollo3.desy.de:80/): Experimental only as yet. [Denmark's Technical Library](http://granit.dtb.dk:2784/): The DTB information service includes the library system. [VOICE magazine](http://isis.cshl.org.:80/main.html): The first global online hypertext magazine? Ed. Tom Boutell [SLAC](http://slacvm.slac.stanford.edu./FIND/SLAC.HTML): Stanford Linear Accelerator, California. HEP preprints database and LOTS more... also a [unix server](http://slacvx.slac.stanford.edu:80/sldwww/000000/browsers.html) . [Technical University of Graz](http://iicm.tu-graz.ac.at:80/ROOT): Information service. Gateway to Hyper-G data. [CCIT Arizona](http://lanka.ccit.arizona.edu:80/usr/local/lib/WWW/default.html): University of Arizona information [Fermilab](http://fnala.fnal.gov:8000/): Documentation from online and offline groups. Also at FNAL, very experimental servers in [Theory](http://fnth02.fnal.gov:80/) , [D0](http://d0sgi5.fnal.gov:80/) , [HEPnet management](http://nhmxw0.fnal.gov:80/) , [ACCESS user consultancy](http://cdsun3.fnal.gov:80/) . [ASIS Software Repository](http://asis01.cern.ch:80/): A server for public domain and CERN software for distribution to CERN members only. The documentation is public. [CERN news](https://cern.la/hypertext/DataSources/NewsFromVM/Overview.md): Various groups, some more active than others - see the full[list](http://crnvmc.cern.ch/NEWS/) [CERN computing documents](http://crnvmc.cern.ch./FIND): A keyword index. [Hebrew University of Jerusalem](http://vms.huji.ac.il/WWW_DIR/default.html): Information service - both in hebrew and English, asssumes a VT terminal with hebrew characters. See also their [TeX database](//noa.huji.ac.il/tex/www/top.html) (July 1992). [Helsinki Technical University](http://otax.tky.hut.fi/tky/info-html/.html): HUT Information tree. [HEPNET](http://nhmxw0.fnal.gov:80/): Experimental server (might move!) run by US HEPNet at FNAL. [ICTP](http://dec3100b.ictp.trieste.it/): Italian physics institute (experimental server) [FUNET](http://info.funet.fi./default.html) information: Finnish Univerity Research Network. [NIKHEF](http://nic.nikhef.nl./user/a03/www/default/NikhefGuide.html): The Dutch High-Energy Physics center. [Software Technology](http://dxsting.cern.ch:80/sting/sting.html): Information from STING organised by Mike Sendall. [VXCRNA help](http://vxcrna.cern.ch:80/help): The VMS help tree on node vxcrna.cern.ch . [WorldWideWeb support](https://cern.la/): information about W3 itself, CERN entry point, and web overviews.

# Algorithms

There are some indexes for for the book, 'Introduction to Algorithms'
by Tom Cormen, Charles Leiserson, and Ron Rivest, all members of Theory
of Computation Group, Laboratory for Computer Science, MIT.

Databases available for search with WAIS are

[Algorithms-bug](https://cern.la/theory.lcs.mit.edu%3A210//i/wais-index/algorithms-bug): list of bug fixe [Algorithms-exercise](https://cern.la/theory.lcs.mit.edu%3A210//i/wais-index/algorithms-exercise) :: list of exercises [Algorithms-suggest](https://cern.la/theory.lcs.mit.edu%3A210//i/wais-index/algorithms-suggest) :: list of suggestions submitted by readers

We also have an e-mail service for bug-report, suggestions, etc. For
more information, please send mail to algorithms@theory.lcs.mit.edu
with a single word 'help' on subject line.

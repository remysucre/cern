# W3 Software

This is a list of products related
to the [WWW project](https://cern.la/hypertext/WWW/TheProject.md) with a link to
a status summary of each one. For
list of previous milestones, releases,
etc, see the "Features" list for
each product, linked to the wish
lists. See also: [getting the files](https://cern.la/hypertext/README.md)
.

[Common Library](https://cern.la/hypertext/WWW/Library/Status.md): The common code library is the basis for most browers. It contains the network access code and format handling.

## Clients [Line Mode Browser](https://cern.la/hypertext/WWW/LineMode/Status.md) This program gives W3 readership to anyone with a dumb terminal. Not as flashy as a windows implementation, it covers a wide class of users who do still not have window facilities, and is a general purpose information retrieval tool. [Curses Browser](https://cern.la/hypertext/WWW/Curses/Status.md) Assumes a character-grid terminal with cursor addressing, and provides a full-screen interface to the web. [Macintosh Browser](https://cern.la/hypertext/WWW/Macintosh/Status.md) WWW browser for the Macintosh. (Pre-alpha.) ["Erwise"](https://cern.la/hypertext/WWW/Erwise/Status.md) WWW browser for X/Motif. (Unsupported). ["ViolaWWW" Browser for X11](https://cern.la/hypertext/WWW/Viola/Status.md) WWW browser for X11. [tkWWW Browser](https://cern.la/hypertext/WWW/TkWWW/Status.md) WWW browser for X11. [MidasWWW](https://cern.la/hypertext/WWW/MidasWWW/Status.md) Browser WWW browser for X/Motif. [Browser-Editor on the NeXT](https://cern.la/hypertext/WWW/NeXT/Status.md) A browser/editor for NeXTStep. Allows wysiwyg hypertext editing. [Browser on CERNVM](https://cern.la/hypertext/WWW/VMClient/Status.md) A W3 browser for VM. Nonexistant. [Tom Fine's Browser](https://cern.la/hypertext/WWW/FineWWW/Status.md) A tty-based browser written in perl. (Beta) Servers [VM server](https://cern.la/hypertext/WWW/FIND/Status.md) A server for VM mainframes. [Generic server](https://cern.la/hypertext/WWW/Daemon/Status.md) A server for unix and VMS systems. A fast file server suitbale on-line documentation, and adaptable to many needs. [VMS/Help gateway](https://cern.la/hypertext/WWW/Daemon/VMSGateStatus.md) Run son a VMS machine and allows webc lient eveywhere to read local VMS/Help files. [Mail Robot](https://cern.la/hypertext/WWW/MailRobot/Status.md) A server which will returns documents by mail, given a request sent by mail. Also manages mailing lists.

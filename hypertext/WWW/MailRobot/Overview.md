# Mail Robot

The mail robot is a program which will accept incoming mail and allow
remote users to:

* Subscribe to mailing lists (and unsubscribe)* Retrieve information given a W3 addresss (URL)

Originally from UC Berkeley, an enhanced robot is distributed as part
of the [world-wide web global information initiative](https://cern.la/hypertext/WWW/TheProject.md). Futhur information
available is:

[Help](https://cern.la/hypertext/WWW/MailRobot/Help.md): The help file for users of the robot service [Installation](https://cern.la/hypertext/WWW/MailRobot/Installation.md): Installation instructions for unix system managers [Bugs](https://cern.la/hypertext/WWW/MailRobot/Bugs.md): Lists of improvements requested or needed. [Change history](https://cern.la/hypertext/WWW/MailRobot/Features.md): A list of features introduced and bugs fixed.

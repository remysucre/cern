# What is HyperText

Hypertext is text which is not constrained to be linear.

Hypertext is text which contains [links](https://cern.la/hypertext/WWW/Terms.md#link) to other texts. The term was
coined by [Ted Nelson](https://cern.la/hypertext/WWW/Xanadu.md#Nelson) around 1965 (see [History](https://cern.la/hypertext/History.md) ).

HyperMedia is a term used for hypertext which is not constrained to
be text: it can include graphics, video and [sound](https://cern.la/hypertext/WWW/Talks/YesWeCan.snd) , for example. Apparently
Ted Nelson was the first to use this term too.

Hypertext and HyperMedia are concepts, not products.

# HTML

The [WWW](https://cern.la/hypertext/WWW/TheProject.md) system uses marked-up text
to represent a hypertext document
for transmision over the network.
The hypertext mark-up language is
an [SGML](https://cern.la/hypertext/WWW/MarkUp/SGML.md) format. WWW parsers should
ignore tags which they do not understand,
and ignore attributes which they
do not understand of tags which they
do understand.

To find out how to write HTML, or
to write a program to generate it,
read the following sections:-

[Default text](https://cern.la/hypertext/WWW/MarkUp/Text.md): How text is interpreted when uninfluenced by tags [The tags](https://cern.la/hypertext/WWW/MarkUp/Tags.md): A list of the tags used in HTML with their significance. [Entities](https://cern.la/hypertext/WWW/MarkUp/Entities.md): Special characters are represented by SGML entities [DTD](https://cern.la/MarkUp/html-spec/html.dtd): The SGML [document type definition](https://cern.la/hypertext/WWW/MarkUp/SGML.md#5) for HTML.

The following do not form part of
the specifciation.

[Example](https://cern.la/hypertext/WWW/Test/test.md): A file containing a variety of tags used for test purposes. See also [finding examples on the web](https://cern.la/hypertext/WWW/MarkUp/FindingExamples.md) . [Future directions](https://cern.la/hypertext/WWW/MarkUp/Future.md): Changes suggested for HTML improvements [Constraints](https://cern.la/hypertext/WWW/MarkUp/HTMLConstraints.md): Design constraints for HTML which might explain some of its properties.
